# 투미 마케팅 가이드

신규 직원용 안내 페이지입니다. 마케팅 설명과 블로그·쇼츠 요청 양식이 들어 있습니다.

- `index.html`: 페이지 전체 (GitHub Pages로 배포)
- `apps-script.gs`: 요청을 구글 시트에 저장하고 메일로 알려 주는 수신기

## 지금 상태

`index.html`의 `SCRIPT_URL`이 비어 있으면 **"요청서 복사 → 카톡으로 보내기"** 방식으로 동작합니다.
아래 1~2단계를 마치면 **요청 보내기 → 구글 시트 저장 + 메일 알림** 방식으로 바뀝니다.

## 요청은 이렇게 받습니다

직원이 **요청 보내기**를 누르면 세 곳에 동시에 들어옵니다.

1. **메일 알림**: 제목 `[투미 블로그 요청] 마천1구역 / 김철수`. 본문 맨 위에 첨부 폴더 링크가 있고, 그 아래에 요청 내용 전체가 들어 있습니다.
   휴대폰 Gmail 앱 알림을 켜 두면 바로 울립니다.
2. **구글 시트** (`투미 마케팅 요청`): 블로그/쇼츠 탭에 한 줄씩 쌓입니다.
   `상태` 칸을 `접수 → 작성중 → 확인요청 → 업로드`로 바꿔 가며 관리하면 됩니다.
3. **구글 드라이브** `투미 마케팅 요청 첨부` 폴더: 요청마다 하위 폴더가 생기고 사진·영상이 저장됩니다.
   예: `20261117_1430 블로그 마천1구역 김철수/01_IMG_1234.jpg`
   PC에 "Google Drive 데스크톱"을 설치하면 탐색기에서 일반 폴더처럼 열립니다.

- 사진은 올리기 전에 긴 변 1920px JPEG로 자동으로 줄여서, 블로그에 바로 쓸 수 있는 크기입니다.
- 한 번에 최대 20개, 합계 30MB까지 올릴 수 있습니다(구글 Apps Script 한도). 더 큰 영상은 직원이 드라이브 링크를 적거나 카톡으로 보냅니다.
- 첨부 폴더는 공유되지 않은 내 드라이브 폴더라 대표님만 볼 수 있습니다.

## 1. 요청 받을 구글 시트 만들기 (5분)

1. 구글 드라이브에서 새 스프레드시트를 만듭니다(예: `투미 마케팅 요청`).
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 코드를 지우고 `apps-script.gs` 내용을 통째로 붙여넣은 뒤 저장합니다.
4. 위쪽 함수 목록에서 `testRequest`를 고르고 **실행**을 누릅니다. 권한 승인 창이 뜨면 허용합니다.
   시트에 `블로그` 탭과 테스트 줄이 생기고, 드라이브에 `투미 마케팅 요청 첨부` 폴더가 생기고, 메일이 오면 정상입니다. 테스트 줄과 폴더는 지워도 됩니다.
   (권한 창에 "확인되지 않은 앱"이 뜨면 **고급 → 이동**을 누르세요. 내가 만든 스크립트라서 뜨는 안내입니다.)
5. **배포 → 새 배포 → 유형: 웹 앱**을 고릅니다.
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
6. 배포 후 나오는 `https://script.google.com/macros/s/…/exec` 주소를 복사합니다.

## 2. 페이지에 주소 넣기

`index.html` 아래쪽에서 다음 줄을 찾아 주소를 넣습니다.

```js
const SCRIPT_URL = "https://script.google.com/macros/s/…/exec";
```

> Apps Script 코드를 고치면 **배포 → 배포 관리 → 수정 → 새 버전**으로 다시 배포해야 반영됩니다. 주소는 그대로 유지됩니다.

## 3. GitHub Pages 배포

저장소의 Settings → Pages에서 `main` 브랜치의 `/ (root)`를 선택하면
`https://<계정>.github.io/<저장소이름>/` 주소로 열립니다.

## 쇼츠 요청 → 영상 만들기

`쇼츠` 시트의 **숏츠메이커 JSON** 칸(대본 한 줄 = 장면 하나, 그림은 내용으로 자동 선택)을 복사해서
`Desktop\투미숏츠메이커\매물\구역명.json`으로 저장한 뒤 실행합니다.

```
node make.mjs 매물\구역명.json
```

## 참고

- 페이지는 공개 주소지만 검색엔진 노출은 막아 두었습니다(`noindex`). 직원에게만 링크를 공유하세요.
- 스팸 봇을 막는 숨은 칸이 있습니다. 그래도 스팸이 오면 Apps Script를 새 주소로 다시 배포하세요.
